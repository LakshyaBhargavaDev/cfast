The Script uses Bash and the existing g++ compiler to work. 

To use this script make it executable and call it with the code to compile. 
like this: ./cfast code.cpp 

The output will be an executable with the same name without the .cpp extension in the same directory. 

I recommend using alias to make the command shorter and be able to use it from any directory in your system. 
  for example cfast code.cpp
